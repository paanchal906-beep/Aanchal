**SolarSaathi**
This is an human friendly project that deals with real human problem..Installing solar panels can save money over time, but the initial cost often makes people unsure about taking the first step.This project  eradicate the  problem as it uses local weather information, roof measurements and
current cost estimates to give users a clearer idea of the budget, expected electricity generation and possible
reduction in carbon emissions.
**1. Cost Estimation & Financial Modeling**
The cost section adds up the main expenses, including solar panels, mounting equipment, the inverter, installation
work and grid connection charges. Where applicable, it also considers subsidies, tax benefits and net-metering rules,
so users can see a more realistic upfront cost.
2. Energy Yield Prediction
The system estimates how much electricity the panels could produce using local sunlight data, typical sunny hours
and temperature patterns. It also checks the roof's angle and direction, along with possible shade from trees or
nearby buildings.
3. Eco-Friendly
Using solar power can reduce the amount of electricity needed from the local grid. This section estimates the related
reduction in carbon dioxide emissions, based on how much electricity the solar system is expected to generate.
To make the figures easier to understand, the report can compare the estimated savings with familiar examples, such
as trees planted or vehicle miles avoided. It also considers the emissions created while manufacturing the panels,
giving a fuller picture of their environmental impact.
